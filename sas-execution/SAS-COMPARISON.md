## How to use this

1. Run `00_fixture.sas` on SAS OnDemand for Academics (free).
2. Point `libname raw` in the emitted `00_setup.sas` at the same folder.
3. Run `00_setup.sas` through `360_suppression.sas` in numeric order.
4. Compare each program's printed output against the rows below.

**A disagreement is a finding.** The SQL side is executed against hand-derived
truth, so if SAS says something else, either the SAS twin is wrong or the
derivation is. Do not adjust one to match the other without working out which.

**A program that does not RUN is the more likely outcome and the more valuable
one.** Nothing here has ever executed SAS. Record the log, not just the result.
